# Group 29 - Final project
Project repository for Group 29

## Dataset

This project uses the data set used in the paper:

> Garfinkel, Alan, et al. **"Prognostic Value of Dobutamine Stress Echocardiography in Predicting Cardiac Events in Patients With Known or Suspected Coronary Artery Disease."** *Journal of the American College of Cardiology*, 33.3 (1999): 708–716.

It can be downloaded directly clicking [here](https://hbiostat.org/data/repo/stressEcho.csv). The information about it can be found [here](https://hbiostat.org/data/repo/stressecho) and the variable descriptions [here](https://hbiostat.org/data/repo/cstressecho).

The dataset is **not included in this repository**.
